#### Priority Issues

- **[P1] What**: Nested card depth inside the Projects grid (`.projects-grid .project-card-apple`) creates container-inside-container visual weight.
  - **Why it matters**: Double borders (window frame + card border) add extraneous cognitive load when browsing multiple projects simultaneously.
  - **Fix**: Flatten the project grid into a borderless bento layout separated by subtle background tonal shifts and clean vertical spacing rather than heavy box borders.
  - **Suggested command**: `/impeccable distill`

- **[P1] What**: Legacy AI color tokens in `core.css` still define unused violet gradients and neon teal variables.
  - **Why it matters**: Residual styles risk accidental styling regression when adding new components or inspecting browser devtools.
  - **Fix**: Purge unused utility gradients and unify the palette to monochrome zinc with sky/slate accents.
  - **Suggested command**: `/impeccable colorize`

- **[P2] What**: Text line measure on maximized windows stretches beyond 75ch if not constrained.
  - **Why it matters**: Long lines force eye strain on wide monitors (1920px+).
  - **Fix**: Apply an explicit `max-width: 68ch` clamp to all textual content panes.
  - **Suggested command**: `/impeccable layout`

- **[P2] What**: Focus trap and keyboard navigation inside modals (Phone QR, Recruiter mode) can lose focus ring.
  - **Why it matters**: Power users and keyboard-only navigators require uninterrupted tab cycling.
  - **Fix**: Add a lightweight tab focus trap in `app.js` when modals are active.
  - **Suggested command**: `/impeccable harden`
